# AI Group Coordinator — Project Reports

This repository stores reports and supporting documentation for the AI Group Coordinator capstone project. It is documentation-only; implementation code and executable scripts are maintained elsewhere.

## Contents

- `Sprints/`: meeting minutes, sprint reports, review presentation drop locations, and demo notes for six sprints.
- `Reports/`: course report sections and traceability records.
- `testing/`, `evaluation/`, and `deployment/`: planning and results documentation.
- `reflections/`: individual and team reflection templates.
- `resources/` and `rubric/`: research links and course outcome references.

## Getting started

Start with [Contributing](CONTRIBUTING.md), then use the relevant template. Replace every `[TODO]` before treating a document as final. Do not add source code, scripts, notebooks, binaries, credentials, or private user data to this repository.
