# Contributing

This repository is for project reports and supporting documentation only.

## Document workflow

1. Choose the appropriate course, sprint, or reflection template.
2. Use clear headings, dates, and links to supporting evidence.
3. Mark unknown information as `[TODO]`; do not guess project facts.
4. Review names, dates, requirements, and links with the team before marking a report final.
5. Keep drafts and approved reports clearly labeled.

## File naming

- Meeting minutes: `MoM_YYYY-MM-DD.md`
- Sprint reports and reviews: use the sprint number in the filename.
- Course report sections: keep the numeric prefixes so sections remain in order.

## Scope

Do not commit implementation code, executable scripts, notebooks, generated binaries, credentials, or private personal data here. Add presentation files only when they are ready to share with the project team.
